WHAT IS A SHADER

    
A shader is a tiny program the graphics chip runs once for every pixel, all at the same time. It answers one question: what colour is this pixel?

    
To answer, it can look up the photo anywhere it likes. Looking somewhere else is how bends, mirrors and smears work. Doing sums on the colour it found is how tone effects work.

    
Here the pane runs only inside the cell. Everything outside is the clean photo, so you can judge how each one sits next to it.
